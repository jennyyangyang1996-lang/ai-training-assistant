# AI企业培训助手 V2（讲稿生成版）

## 📌 项目简介

AI企业培训助手 V2 是一个基于 Node.js + DeepSeek API + Prompt Engineering 构建的轻量级AI应用。

本版本从“企业问答系统（V1）”升级为“企业培训讲稿生成器（V2）”，能够将企业制度内容自动转换为可用于口播的培训讲稿。

---

## 🎯 项目目标

将企业内部的制度说明、流程文档等内容，通过AI自动转换为：

- 结构清晰
- 口语化表达
- 可直接用于培训讲解的讲稿

用于提升企业内部培训效率，减少重复讲解成本。

---

## 🧠 核心能力

- 输入一个培训主题（如：报销流程）
- 自动生成结构化培训讲稿
- 支持口语化表达（适合新员工培训）
- 输出可直接用于口播内容

---

## 🏗️ 技术栈

- Node.js（后端服务）
- HTTP 原生模块
- Axios（API调用）
- DeepSeek API（大模型能力）
- Prompt Engineering（核心能力设计）

---

## 🔄 系统流程

```

用户输入（培训主题）
↓
Node.js 后端接收请求
↓
读取企业知识库（company.txt）
↓
构建 Prompt（角色 + 规则 + 知识）
↓
调用 DeepSeek API
↓
生成培训讲稿
↓
返回前端展示

```

---

## ✨ Prompt设计（核心）

```text
你是一名企业培训讲师，请生成标准化培训讲稿。

要求：
1. 语言口语化，但不要过于聊天
2. 结构清晰：开场 → 核心步骤（3-5点） → 总结
3. 每一部分要有逻辑，不要发散
4. 控制长度在1分钟口播内容
5. 不要出现无关公司信息

【企业知识】
{{knowledge}}

【培训主题】
{{topic}}
```
